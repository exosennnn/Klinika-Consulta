FONTS FOLDER - Klinika Consulta

Place these two free (SIL Open Font License) variable font files here so the
public site uses the intended typefaces, even when the internet is offline:

  1. plus-jakarta-sans.woff2  (headings)
     Download: https://fonts.google.com/specimen/Plus+Jakarta+Sans
  2. inter.woff2               (body text)
     Download: https://fonts.google.com/specimen/Inter

Tip: on the Google Fonts page, choose "Download family", open the zip, and
convert the variable .ttf to .woff2 (any free converter), or use the
"Variable" .woff2 files from the Google Fonts GitHub repository.

If the files are missing, the site falls back to Segoe UI / system-ui, so
nothing breaks.
